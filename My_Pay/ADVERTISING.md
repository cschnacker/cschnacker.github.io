# AdSense

My Pay uses the Effective Tax Rate Calculator publisher: `ca-pub-5436594780163482`.
The asynchronous Google AdSense script loads once in the `index.html` head. A responsive display placement labeled Advertisement appears below the calculator, using the owner-supplied ad-unit slot `9809430962`. Its format is `auto` and full-width responsiveness is enabled as in the supplied snippet. The same loader also supports account-controlled Auto ads.

Ad delivery depends on approval of the production site and the AdSense account. The manual bottom placement does not require Auto ads to be enabled. Configure regional consent messages in AdSense Privacy & messaging where applicable before enabling ad delivery. This app does not supply a certified consent platform.

The included `ads.txt` identifies this publisher. For a GitHub project site, also place that entry at the root of the hosting domain, for example `https://cschnacker.github.io/ads.txt`; the project subfolder's file alone is not the domain-root file. Verify the entry against the AdSense account before publishing.

Privacy disclosures describe the third-party advertising script. Calculator code does not send entered amounts to an advertising service. Third-party requests are not stored by the offline service worker.

Sources: [Google AdSense code](https://support.google.com/adsense/answer/9274019), [ads.txt](https://support.google.com/adsense/answer/12171612).
